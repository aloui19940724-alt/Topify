# Topify - متجر الخدمات الرقمية

## 📱 نبذة عن المشروع

Topify هو متجر إلكتروني حديث متخصص في بيع الخدمات الرقمية والاشتراكات المدفوعة مثل:
- 🎮 شحن الألعاب (PUBG, Free Fire, إلخ)
- 📺 الاشتراكات الشهرية (YouTube Premium, ChatGPT, Google AI Plus)
- 🤖 أدوات الذكاء الاصطناعي
- 🎁 بطاقات الهدايا الرقمية

## 🎯 الميزات

✅ **واجهة مستخدم حديثة وجذابة**
- تصميم مظلم احترافي
- تجربة مستخدم سلسة وسهلة
- دعم الأجهزة المختلفة (Responsive)

✅ **بحث وتصفية سريعة**
- بحث فوري عن المنتجات
- تصفية حسب الفئات
- تحديث البيانات بدون تحديث الصفحة

✅ **تكامل مع WhatsApp**
- طلب مباشر عبر WhatsApp
- رسائل مخصصة تلقائياً

✅ **تحسينات الأداء**
- جلب البيانات من JSON
- Debouncing على البحث
- Event Delegation للمنتجات

✅ **أمان وخصوصية**
- متغيرات البيئة للبيانات الحساسة
- عدم فضح الأرقام والمعلومات الخاصة

✅ **ميزات إضافية**
- نظام المفضلة (localStorage)
- معالجة الأخطاء والحالات الفارغة
- صور Placeholder عند فشل التحميل

## 🛠️ المتطلبات

- متصفح حديث (Chrome, Firefox, Safari, Edge)
- لا توجد متط��بات تثبيت إضافية

## 🚀 كيفية البدء

### الطريقة الأولى: فتح مباشر في المتصفح

1. انسخ المشروع أو فك ضغط الملفات
2. افتح ملف `index.html` في المتصفح مباشرة
3. ابدأ الاستخدام! 🎉

### الطريقة الثانية: استخدام Local Server

```bash
# استخدام Python 3
python -m http.server 8000

# أو استخدام Node.js
npm install -g http-server
http-server

# ثم افتح المتصفح وانتقل إلى:
# http://localhost:8000
```

## 📝 إضافة منتجات جديدة

عدّل ملف `products.json`:

```json
[
  {
    "name": "اسم المنتج",
    "price": "15 DT",
    "image": "images/product.jpg",
    "category": "games"  // أو "subscriptions", "ai-tools", "gift-cards"
  }
]
```

## ⚙️ التكوين

عدّل ملف `config.js` لتخصيص الإعدادات:

```javascript
const CONFIG = {
  WHATSAPP_PHONE: '21655234874',  // رقم WhatsApp
  SEARCH_DEBOUNCE: 300,            // تأخير البحث بالميلي ثانية
  STORE_NAME: 'Topify',            // اسم المتجر
};
```

## 🎨 تخصيص الألوان والأنماط

عدّل ملف `css/variables.css`:

```css
:root {
  --primary-color: #f5c542;      /* اللون الأساسي */
  --bg-primary: #0f0f0f;         /* لون الخلفية */
  /* ... والمزيد */
}
```

## 🌍 الدعم الدولي

## 📊 الأداء

- ⚡ أداء سريع جداً
- 🎯 استهلاك بيانات منخفض
- 📱 محسّن للهواتف الذكية
- 🔄 بدون جلب بيانات غير ضرورية

## 🔒 الأمان

✅ لا يتم حفظ بيانات حساسة في الكود
✅ استخدام متغيرات البيئة
✅ بدون معالجة بيانات دفع (WhatsApp فقط)
✅ محمي من XSS attacks (Escaping)

## 🐛 حل المشاكل الشائعة

### المنتجات لا تظهر
- تحقق من وجود ملف `products.json`
- افتح المتصفح وتحقق من Console (F12) للأخطاء

### الصور لا تحمل
- تأكد من وجود صور المنتجات في مجلد `images/`
- تحقق من أسماء الملفات والامتدادات

### البحث بطيء
- تم تحسينه بـ Debouncing
- إذا استمرت المشكلة، قلل عدد المنتجات أو استخدم Backend
